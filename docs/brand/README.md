# EVGO brand

Logo supplied by the EVGO team: `evgo-logo-original.png`. `evgo-logo.png` is the same
logo with a transparent background, trimmed. `evgo-icon-1024.png` is the plug "e" on white,
used for app icons and favicons.

Colours sampled from the logo's gradient, left to right:

| Token | Hex | Use |
| --- | --- | --- |
| `blue` | `#0474B4` | Primary actions, links |
| `teal` | `#04909C` | Seed colour for the app theme |
| `green` | `#20A874` | Success, charging available |
| `lime` | `#70C84C` | Highlights, gradient end |
| `ink` | `#0B2A3A` | Text on light backgrounds |

Brand gradient: `linear-gradient(90deg, #0474B4, #04909C 35%, #20A874 65%, #70C84C)`.

The same values live in `packages/brand/brand.json` for code.
